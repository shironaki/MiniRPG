Репозиторий: https://github.com/shironaki/MiniRPG

Ветка main: старая рабочая MiniRPG, НЕ ломать и не использовать для экспериментов.

## 2. КОНЦЕПЦИЯ
Shadow Ascension — оригинальная браузерная action-RPG в духе Solo Leveling.
Мы используем удобные top-down механики, комнаты, порталы и управление, вдохновлённые Soul Knight, но НЕ делаем клон.

Главная фантазия игрока:
войти в подземелье → сражаться → прокачиваться → получать добычу → побеждать сильных врагов → извлекать их тени → собирать собственную армию теней.

## 3. ПЛАТФОРМА
Основной вариант: HTML + CSS + JavaScript + Canvas.
Цель: один проект должен работать на ПК, Android, iPhone и планшетах через браузер.
Позже при необходимости: PWA / APK или другая упаковка.
Пока не переходить на другой движок без необходимости.

## 5. БЛИЖАЙШИЙ ЭТАП
НЕ добавлять сразу монстров.
Сначала:
1. исправить безопасный spawn;
2. улучшить top-down движение;
3. добавить направление взгляда/прицеливания независимо от движения;
4. сделать второй виртуальный joystick для aim;
5. атака должна идти в сторону прицела;
6. улучшить dodge;
7. добавить двери/порталы;
8. вход в портал должен переводить в следующую комнату/этаж;
9. после проверки этого этапа добавить первого полноценного врага.

## 8. ПРИНЦИП РАЗРАБОТКИ
Работать маленькими проверяемыми этапами.
После каждого крупного изменения пользователь запускает GitHub Pages и сообщает результат.
Не давать сразу огромную пачку несвязанных изменений.
Перед изменением структуры репозитория сначала сверять фактические имена файлов.
Старую main не ломать.
Если появляется ошибка — сначала исправлять её, а не добавлять новые системы поверх.
