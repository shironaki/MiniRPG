## 2. КОНЦЕПЦИЯ
Shadow Ascension — оригинальная браузерная action-RPG в духе Solo Leveling.
Мы используем удобные top-down механики, комнаты, порталы и управление, вдохновлённые Soul Knight, но НЕ делаем клон.

Главная фантазия игрока:
войти в подземелье → сражаться → прокачиваться → получать добычу → побеждать сильных врагов → извлекать их тени → собирать собственную армию теней.

## 3. ПЛАТФОРМА
Основной вариант: HTML + CSS + JavaScript + Canvas.
Цель: один проект должен работать на ПК, Android, iPhone и планшете через браузер.
Позже при необходимости: PWA / APK или другая упаковка.
Пока не переходить на другой движок без необходимости.

## 7. ВАЖНЫЙ ТЕКУЩИЙ МОМЕНТ
Новая графика персонажа/интерфейса пока НЕ подключена как внешние PNG-ассеты: текущий персонаж и враг всё ещё рисуются Canvas-примитивами.
Следующий графический этап — создать каталог ассетов и подключить подготовленные отдельные изображения непосредственно к рендеру.

План ассетов:
- `assets/player/portrait.png`
- `assets/player/player.png` или набор directional sprites
- `assets/enemies/...`
- `assets/ui/...`
- `assets/world/...`

Конкретные размеры каждого ассета сверять с фактическим способом рендера перед подключением. Не объединять отдельные ассеты в один лист, если это не требуется системой анимации.

## 8. БЛИЖАЙШИЙ ЭТАП
Продолжать без лишних остановок, но изменения делать небольшими проверяемыми группами:
1. Создать структуру `assets/`.
2. Подключить подготовленный portrait/UI-ассет, если файл уже доступен в репозитории/рабочем контексте.
3. Перевести player render с примитивов на новый player asset без изменения физики.
4. Сделать корректное направление взгляда/анимацию.
5. Довести aim + attack визуально.
6. Улучшить dodge.
7. Сделать порталы полноценным переходом между комнатами.
8. Затем заменить тестового врага полноценным enemy asset/классом.
9. После этого — AI врага.
10. Затем двери, комнаты, elite и boss.
